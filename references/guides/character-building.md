# 人物设计指南


## 反派设计原则

**不让反派认为自己"坏"**——反派的行动必须有自洽的逻辑体系。

### 反派层次

| 层级 | 类型 | 示例 |
|------|------|------|
| L1 | 本能型 | 纯粹的恶，为利益/欲望驱动 |
| L2 | 理念型 | 有自己坚信的价值观，只是在主角的对立面 |
| L3 | 镜像型 | 与主角起点相似但走向不同道路，是主角的"如果"版本 |
| L4 | 悲情型 | 曾经是好人，因创伤/背叛而黑化 |

**最佳实践**：让 L3/L4 反派成为主要对手，配 L1 作为阶段性小Boss。

## 配角功能分类

| 类型 | 功能 | 数量建议 |
|------|------|---------|
| **挚友** | 情感支持，主角性格的镜子 | 1-2 |
| **导师** | 提供知识/能力/指引 | 0-1 |
| **搞笑担当** | 调节气氛 | 0-1 |
| **移动工具人** | 提供信息/资源/通道 | 1-2 |
| **炮灰** | 展示世界残酷性/反派的可怕 | 按需 |

**原则**：配角不是工具人，每个配角有自己独立的目标（虽然不一定要展开）。

## 角色群像管理

### 命名策略
- 主要角色：全名 + 外号/头衔（增加记忆点）
- 配角：姓 + 职业/特征（李医生、高个子女）
- 龙套：只出现特征不出现名字

### 登场密度
- 单章同时活跃角色 ≤ 5 人
- 每 10 章引入新角色的频次 ≤ 3 人
