# 多视角审稿系统

## 审稿概述

在完成全部章节后，启动 4 个 Agent 从不同角度审稿，确保作品质量。

---

## 视角一：读者视角

**评分维度**（单项 1-10 分）：

| 维度 | 评分标准 |
|------|---------|
| **可读性** | 文字是否流畅易懂，有无阅读障碍 |
| **吸引力** | 开篇是否抓人，是否有持续阅读动力 |
| **节奏感** | 情节推进速度是否合适，有无拖沓或跳跃 |
| **情感共鸣** | 能否引起读者情感反应 |
| **记忆点** | 是否有让人印象深刻的情节/角色/台词 |

**审稿人设**：目标读者画像中的典型读者，以"我"的口吻给出阅读感受。

---

## 视角二：编辑视角

**评分维度**（单项 1-10 分）：

| 维度 | 评分标准 |
|------|---------|
| **结构完整性** | 起承转合是否完整，有无结构缺陷 |
| **逻辑一致性** | 情节逻辑是否自洽，有无矛盾 |
| **语言质量** | 用词是否精准，有无语病 |
| **人物弧光** | 角色是否有成长和变化 |
| **主题表达** | 核心主题是否得到有效传达 |

**审稿人设**：专业文学编辑，以冷静专业的口吻给出修改建议。

---

## 视角三：平台视角（按目标平台）

### 起点中文网标准

| 维度 | 说明 |
|------|------|
| 爽点密度 | 每章是否有 1-2 个爽点 |
| 升级感 | 主角实力/地位持续提升 |
| 世界观厚度 | 设定是否新颖且自洽 |
| 更新节奏 | 每章结尾是否让人期待下一章 |

### 番茄小说标准

| 维度 | 说明 |
|------|------|
| 前三章留存 | 开篇 3 章能否吸引读者继续 |
| 情绪过山车 | 情绪起伏是否够大 |
| 代入感 | 读者能否代入主角 |
| 完读率预期 | 整体故事是否让人想看完 |

### 晋江文学城标准

| 维度 | 说明 |
|------|------|
| 人设吸引力 | 男女主人设是否有魅力 |
| 情感浓度 | 感情线是否足够细腻 |
| CP 感 | 男女主互动是否有化学反应 |
| 甜虐平衡 | 甜/虐比例是否合理 |

### 知乎盐言标准

| 维度 | 说明 |
|------|------|
| 一句话钩子 | 能否一句话抓住读者 |
| 反转质量 | 反转是否出人意料又合理 |
| 情感冲击 | 结尾是否有情感余韵 |
| 完读率 | 短篇是否能让人一口气读完 |

---

## 视角四：毒点排查

**排查清单**：

### 逻辑硬伤
- [ ] 时间线矛盾（同时发生两件不可能同时发生的事）
- [ ] 空间错误（距离/位置不合理的移动）
- [ ] 力量体系矛盾（之前设定的限制被突破但无合理解释）
- [ ] 信息不一致（同一信息在不同章节矛盾）

### 人设崩塌
- [ ] 角色做出不符合其设定的行为
- [ ] 智商强行下线推动剧情
- [ ] 反派降智配合主角
- [ ] 主角光环过强失去紧张感

### 注水段落
- [ ] 过度描写的环境/外貌（超过 200 字的纯描写）
- [ ] 不必要的内心戏（反复纠结同一件事）
- [ ] 重复信息（同一件事多人复述）
- [ ] 战斗描写疲劳（同一类型的战斗反复出现）

### 读者雷区
- [ ] 虐主过头（读者失去希望）
- [ ] 感情线恶心（强行误会/第三者）
- [ ] 强行发便当（重要角色无意义死亡）
- [ ] 降智打脸（反派强行被打脸）

---

## 审稿输出格式

```markdown
# 审稿报告 — 《书名》

## 总览
综合评分：x/10

## 读者视角 (评分：x/10)
[阅读感受]

## 编辑视角 (评分：x/10)
[修改建议]

## 平台视角 — {平台名} (评分：x/10)
[平台适配分析]

## 毒点排查
- 发现 x 个问题
[问题清单及修复建议]

## 优先修改项
1. [最重要的问题]
2. [次重要的问题]
3. ...
```
