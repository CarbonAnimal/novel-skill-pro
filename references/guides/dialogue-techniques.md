# 对话技法

## 对话的四个层次

| 层次 | 功能 | 占比建议 |
|------|------|---------|
| **推进剧情** | 传递关键信息、做出决定 | 30% |
| **塑造人物** | 展现性格、态度、价值观 | 30% |
| **制造冲突** | 争论、对抗、误解 | 25% |
| **营造氛围** | 闲谈、日常对话 | 15% |

---

## 节奏控制

### 语速五档

| 档位 | 特征 | 适合场景 |
|------|------|---------|
| 短促 | 1-3 字一句 | 紧急/愤怒/命令 |
| 快节奏 | 短句连连，不停顿 | 对峙/辩论/激动 |
| 正常 | 有问有答 | 日常交流 |
| 缓慢 | 长句、停顿多 | 思考/坦诚/悲伤 |
| 断续 | 话说一半、沉默 | 犹豫/隐瞒/情绪崩溃 |

### 节奏变化信号

用动作/环境打断对话来调整节奏：
- "他一拳砸在桌上。" → 中断正常节奏，进入激烈
- "沉默了很久。" → 中断快速节奏，进入深沉
- "窗外一声巨响。" → 外部事件打断对话

## 潜台词技法

**原则**：角色说的话 ≠ 角色想说的 ≠ 读者应该理解的

### 潜台词创作三步法

1. **确定表层台词**：角色说了什么
2. **确定真实意图**：角色为什么说这个（ta 真正想表达什么）
3. **设计读解线索**：读者如何从台词中读出真实意图

### 示例

> 表层："你今晚还回来吗？"
>
> 潜台词（吃醋）："我知道你要去见那个女人。"
>
> 读者读解线索：她问的时候没看他，手里的杯子捏得很紧。

## 信息控制

### 对话中的信息披露

**黄金规则**：永远不要让人物说出 ta 不会说的话，只是为了告诉读者信息。

| 手法 | 说明 | 示例 |
|------|------|------|
| **冰山对话** | 说 30%，藏 70% | 用省略号和沉默代替信息 |
| **冲突曝露** | 在争吵中泄露信息 | 吵架时说漏嘴 |
| **无意透露** | 角色不经意说出关键信息 | 随口一句话被有心人听到 |
| **逆向解读** | 通过角色"没说什么"传递信息 | 避开了某个话题 |

## 对话模式数据库

### 高频对话模式

| 模式 | 结构 | 适用 |
|------|------|------|
| **问答链** | A问 → B答(不完整) → A追问 → B被迫回答 | 信息揭露 |
| **一来一回** | 日常交流的平衡模式 | 日常/感情戏 |
| **打断式** | A说 → B打断 → A说 → B打断 | 争执/辩论 |
| **独白式** | 一方大段讲述 + 另一方简短回应 | 揭秘/表白 |
| **沉默式** | 大量动作和环境描写穿插少量对话 | 情感张力场景 |

## 对话自查清单

- [ ] 遮住名字后，能分辨是谁在说话吗？
- [ ] 每段对话是否推进了剧情/塑造了人物/制造了冲突？（至少一项）
- [ ] 是否有"废话对话"？（纯粹为了凑字数或传递无关信息）
- [ ] 对话标签是否多样化？（不要每一句都用"说"）
- [ ] 是否有适当的动作/环境穿插？（避免纯对话块超过 8 行）
