# 情绪设计系统

## 6 种情绪弧形模板

### 1. 英雄之旅弧（上升型）
```
情绪 → 低谷 → 觉醒 → 攀升 → 巅峰 → 回归
```
适合：成长类、逆袭类、修仙类

### 2. 悲剧弧（下降型）
```
正常 → 裂缝 → 坠落 → 挣扎 → 彻底崩溃 → 余响
```
适合：现实向、悬疑悲剧、文艺类

### 3. 过山车弧（震荡型）
```
低 → 高 → 低 → 高 → 低 → 反转高
```
适合：悬疑、冒险、都市爽文

### 4. 双峰弧（双高潮型）
```
铺垫 → 小高潮 → 回落 → 大高潮 → 余韵
```
适合：感情线+剧情线双线并行

### 5. 镜像弧（对比型）
```
主角情绪 ────────
                 对比线
配角/对手情绪 ────
```
适合：正反派视角切换、双主角

### 6. 单元弧（模块型）
```
每卷/每单元独立情绪弧，卷间有情绪主题递进
```
适合：单元剧式长篇（探案/冒险）

## 期待感管理

### 三层期待系统

| 层级 | 时间跨度 | 内容 | 示例 |
|------|---------|------|------|
| **短期期待** | 1-3章 | 当前冲突的解决 | 主角能否逃出密室？ |
| **中期期待** | 1-2卷 | 阶段性目标的达成 | 能否通过宗门考核？ |
| **长期期待** | 全书 | 终极悬念 | 主角的身世之谜是什么？ |

### 期待感的建立与释放

1. **建立**：清晰告知"有什么可期待的"
2. **延迟**：在解答前设置障碍和弯路
3. **释放**：在最佳时机给出满足感
4. **循环**：释放一个期待的同时建立新的期待

### 常见错误

- ❌ 期待建立后拖太久不解答 → 读者失去耐心
- ❌ 解答太轻易 → 读者觉得无聊
- ❌ 只建立不释放 → 读者被吊胃口太久
- ❌ 没有期待就去推进剧情 → 读者不知道为什么要在意

## 情绪曲线设计要诀

1. **每一章都有起伏**，不能是平线
2. **高潮前必须有压抑**，对比产生冲击
3. **情感变化要递进**，不能跳变
4. **不同角色有不同情绪线**，交织产生戏剧张力
5. **留白与爆发的节奏**：7分压抑 + 3分爆发
