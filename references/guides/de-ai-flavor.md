# 去AI味指南 — 三遍去除法 + 量化限制检查

## 为什么需要去AI味

AI 生成的文字往往有以下特征：
- 句式结构过于工整对称
- 逻辑表述过多，感官描写不足
- 情感表达抽象化，缺乏具象细节
- 人物说话风格趋同
- 滥用总结性、过渡性套话

---

## 第一遍：替换 AI 标记句式

### 禁用词表

| 类别 | 禁用表达 | 替换建议 |
|------|---------|---------|
| 因果总结 | "不仅...而且..."、"既有...也有..."、"既...又..." | 拆成两个句子，或用具体描写替代 |
| 强行过渡 | "总而言之"、"综上所述"、"由此可见" | 用动作或场景切换自然过渡 |
| 抽象概括 | "令人感到"、"让人不由地" | 直接写感受，不要加"令人/让人" |
| 过度解释 | "这说明"、"这意味着"、"这代表着" | 留白，让读者自己体会 |
| 情感标签 | "他感到愤怒"、"她觉得悲伤" | 用行为展示情绪："他攥紧了拳头" |
| 逻辑连接 | "然而"、"但是"、"于是"、"因此" | 减少连词，用情节本身推动 |
| 废话铺垫 | "众所周知"、"众所周知"、"在某一天" | 直接进入场景 |

### 句式变体原则

- 把"因为A所以B"变成"A发生了。紧接着B。"
- 把"他不仅聪明而且勇敢"变成"他三秒就看穿了漏洞。他没有犹豫就冲了上去。"
- 把"这种感觉让人难以形容"变成具体的感官描写

## 第二遍：注入感官细节

### 五感描写清单

对照检查每 500 字是否至少包含 2 种感官描写：

| 感官 | 检查项 | 示例 |
|------|--------|------|
| **视觉** | 颜色、光线、形状、动作 | "夕阳把她的影子拉得很长，像一条灰蓝色的裂缝" |
| **听觉** | 声音的远近/高低/质地 | "走廊尽头的脚步声越来越近，橡胶鞋底蹭着水泥地" |
| **嗅觉** | 气味来源/浓度/变化 | "消毒水和咖啡混在一起的味道，是这家医院特有的" |
| **触觉** | 温度/质地/压力 | "铁栏杆被正午的太阳晒得烫手" |
| **味觉** | 味道层次/余味 | "水有股铁锈味，但他渴得顾不上了" |

### 具象化原则

- ❌ "他很疲惫" → ✅ "他的眼睛干涩得眨一下都疼，手指在键盘上抖"
- ❌ "房间很破旧" → ✅ "墙皮像头皮屑一样往下掉，天花板上的水渍画着地图"
- ❌ "气氛紧张" → ✅ "没有人说话。只有空调外机在嗡嗡响。她听见自己的心跳。"

## 第三遍：注入角色个性化语言

### 每个人物的说话方式检查

| 检查维度 | 说明 |
|---------|------|
| **口头禅** | 每个主要角色有 1-2 个习惯用语 |
| **句式偏好** | 短句还是长句？直接还是迂回？ |
| **词汇级别** | 用词是否符合角色的教育水平/职业/年龄？ |
| **节奏** | 急性子说话快而短，慢性子说话长而慢 |
| **情绪透露** | 生气时的说话方式变化是什么？ |

### 对话标签多样化

- ❌ 全用"说"：他说……她说……
- ✅ 多样化：低声道 / 冷笑一声 / 头也不抬 / 把烟掐灭 / 顿了顿
- 规则：每段对话至少用不同的引导方式

## 改写范例

### 改写前（AI 味重）

> 李明的内心充满了复杂的情绪。他既感到愤怒，又感到无奈。这种矛盾的心理让他难以抉择。经过深思熟虑，他最终做出了一个艰难的决定。他深吸一口气，走出了房间。

### 改写后

> 李明把打火机按了七次，火苗跳了七下，全灭了。
>
> 桌上那份合同还在。他的指关节捏得发白。
>
> 第八次，他没点烟，直接推门出去了。

## 去AI味自查清单

- [ ] 没有"不仅...而且...""总而言之"等过渡套话
- [ ] 每 500 字至少 2 种感官描写
- [ ] 主要角色说话方式有明显区别
- [ ] 情感用行为展示，不直接陈述
- [ ] 没有过度解释（留白给读者）
- [ ] 句式有变化（长短句交替，不是每句都工整对称）
- [ ] 至少 3 处独特的细节描写（只有这个角色/这个场景才有）

## 第四遍（追加）：量化限制检查

> 此步骤在完成三遍去AI法后执行，对全章做硬性量化指标检查。**必须全部达标才算去AI味完成。**

### 量化限制清单（每章）

| 指标 | 限制 | 检查方法 |
|------|------|---------|
| 环境描写 | 每段 ≤2 句 | 扫一遍全文，连续环境描写超过2句的段落需拆分或压缩 |
| 排比句 | 每章 ≤1 次 | 搜索"……，……，……"式的三连结构，最多保留1处 |
| 比喻句 | 每章 ≤3 次 | 搜索"像""仿佛""如同""似的""一样"等比喻关键词，超限则删或用直述替代 |
| "他/她/它"频率 | 尽可能降低 | 用动作描写、称谓（"老王""那家伙"）、身份（"保安""医生"）替代代词 |
| 句式工整度 | 长短交替，避免工整对仗 | 连读3句，如果结构相似（都是主谓宾或都是XX的XX），改其中1-2句 |
| 玩梗 | 每章 ≤2 处（且贴合背景） | 检查是否有强行玩梗破坏氛围的情况 |

### 操作流程

1. **扫描全文** — 使用搜索功能扫描比喻词和排比结构
2. **统计计数** — 对每个指标计数，记录超限项
3. **逐一修复** — 超限项按以下优先级删改：
   - 最冗余的先删 → 保留1-2个最有力的比喻/排比
   - 环境描写过长的段落：把一部分搬到动作或对话中表现
   - "他/她/它"过多的句子：用具体称谓或动作替代主语
4. **二次扫描** — 修复后再扫一遍确认达标

### 量化限制违反处理

**严重违规（+50%超限）** → 整段重写该部分
**轻微违规（<50%超限）** → 按优先级逐一删改
**3轮修复仍不达标** → 标记"需人工干预"

### 范例：量化修复前后对比

**修复前（排比3次，比喻5次）：**
> 夕阳像一团火，像一枚铜钱，像一个被捏碎的蛋黄，缓缓沉入地平线。暮色像潮水一样涌来，黑暗像墨汁一样浸染了天空。远处的山峰像沉默的巨兽，像沉睡的巨人，像凝固的浪涛。

**修复后（排比1次，比喻2次）：**
> 夕阳像一个被捏碎的蛋黄，缓缓沉入地平线。暮色涌来，黑暗浸染了天空。远处山峰沉默着，像沉睡的巨人。
