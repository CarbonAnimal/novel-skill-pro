# 女频写作专项

## 女频读者核心偏好

| 维度 | 说明 |
|------|------|
| **情感浓度** | 感情描写要细腻、有层次，先甜后虐或先虐后甜都可以，但不能平淡 |
| **人设吸引力** | 男主必须有魅力点（苏感）：颜值/能力/深情/反差萌（至少2项） |
| **CP 感** | 男女主互动要有拉扯感，从互不待见到互相在意，过程要长 |
| **代入感** | 女主不能太弱（容易被骂），也不能太强（没代入感），"成长型"最佳 |
| **安全感** | 男主对女主的"唯一性"和"偏爱感"必须要体现 |

---

## 感情线四阶段模型

| 阶段 | 说明 | 篇幅占比 |
|------|------|---------|
| **初遇** | 第一次见面留下深刻印象（不一定是好印象） | 10% |
| **拉扯** | 互相试探、误解、斗嘴、在意但不承认 | 40% |
| **升温** | 确定心意后的甜蜜、共同面对困难 | 30% |
| **考验** | 外部/内部冲突考验感情 | 20% |

**关键原则**：
- 拉扯阶段要长，这是读者最上头的时候
- 确定关系后要有持续的小冲突和小甜蜜交替
- 不能因为外部困难就让感情变质（比如被迫分开多年）

## 情感描写技巧

### 不要直接写"她喜欢他"

而要通过：
- 她注意到他的小习惯
- 她因为他的一句话开心/失落一整天
- 她在人群中第一个找到他
- 她为他做了不合逻辑的事
- 她开始介意他和其他异性的互动

### 小细节的情感力量

| 类型 | 示例 |
|------|------|
| 动作细节 | "他自然地把伞倾向她那边，自己的半边肩膀全湿了。" |
| 物品细节 | "他记得她三个月前随口说想吃的那家店。" |
| 对比细节 | "他对所有人冷淡，只有跟她说话时语气软下来。" |
| 习惯细节 | "她发现自己开始喝和他一样的咖啡。" |

## 女频避雷指南

| 雷区 | 说明 |
|------|------|
| **男主不洁** | 男主和女配有过实质亲密关系 |
| **男主渣化** | 男主对女主态度恶劣（除非是"追妻火葬场"类型且有充足反转） |
| **女主恋爱脑** | 女主为男主放弃事业/尊严/智商 |
| **男二太强** | 男二比男主更吸引人，导致读者站错CP |
| **降智误会** | 因为不沟通造成的愚蠢误会（读者会骂） |
| **工具人女配** | 纯粹为了衬托女主或搞破坏的女配 |
