`~/.workbuddy/skills/chinese-novelist-pro/user-preferences.json`

```json
{
  "version": "1.0",
  "last_updated": "2026-05-21T12:00:00Z",
  "preferences": {
    "genre": {"悬疑": 0.8, "奇幻": 0.5, "都市": 0.3},
    "style": {"第一人称": 0.7, "轻松": 0.6, "暗黑": 0.4},

    "chapter_count": {"20-30": 0.8, "30-50": 0.4},
    "target_reader": {"男频": 0.6, "女频": 0.4},
    "platform": {"起点": 0.7, "番茄": 0.5},
    "main_character": {"复仇者": 0.6, "普通人觉醒": 0.5}

```

### 学习机制

每次创作完成，根据用户实际选择更新偏好权重：
- 完全匹配 → +0.2 权重
- 部分匹配 → +0.1 权重
- 长期不选 → -0.05 权重/次（衰减）

## 追踪系统

### 目录结构

```
{项目名}/追踪/
├── 上下文.md       # 紧凑上下文（compact 恢复用）
├── 伏笔.md         # 伏笔状态表
├── 时间线.md       # 故事内时间线
└── 角色状态.md     # 角色当前状态快照
```

### 上下文.md

压缩后的创作上下文摘要，包含：
- 当前进度（已完成章节/当前章节）
- 上一章结尾摘要（200字以内）
- 当前开放的伏笔列表
- 关键角色当前状态

### 伏笔.md

| 伏笔ID | 描述 | 埋设章节 | 计划回收章节 | 状态 | 关联角色 |
|--------|------|---------|------------|------|---------|
| F001 | 神秘手机的主人 | 第01章 | 第08章 | 开放 | 主角 |
| F002 | 列车时刻表矛盾 | 第03章 | 第12章 | 开放 | 列车长 |

### 时间线.md

按章节追踪故事内时间：

| 章节 | 故事时间 | 主要事件 | 时间跨度 |
|------|---------|---------|---------|
| 第01章 | Day 1, 23:00-23:30 | 主角乘末班列车 | 30分钟 |
| 第02章 | Day 1, 23:30-Day 2, 02:00 | 发现首位失踪乘客 | 2.5小时 |

### 角色状态.md

按章节追踪关键角色状态：

| 角色 | 当前状态 | 位置 | 手持/拥有 | 情感状态 | 目标 |
|------|---------|------|---------|---------|------|
| 陈默(主角) | 清醒 | 列车第4车厢 | 手机(未知号码来电)、警徽 | 困惑、警觉 | 找出真相 |
| 林小雨 | 失踪 | 未知 | 手机(关机) | - | - |

## 字数检查脚本

### 使用方法

```bash
# 检查单个章节
python scripts/check_chapter_wordcount.py 第01章.md

# 检查整个目录
python scripts/check_chapter_wordcount.py ./正文 3000 5000
```

### 字数统计规则

- 统计中文字符数（\u4e00-\u9fff 范围）
- 不包含标点符号、空格、英文
- 目标范围：长篇 3000-5000 字/章，短篇 1000 字/节
